東京メトロの「メトロポイントクラブ(メトポ)」会員向けサービスで発生した不正アクセスについて、要点だけさくっとまとめました。

## ざっくり概要

| 項目 | 内容 |
| --- | --- |
| 企業名 | 東京地下鉄株式会社(東京メトロ) |
| サービス | メトロポイントクラブ(メトポ)会員向けサービス |
| 被害件数 | 約59,000件(メールアドレス) |
| 公表日 | 2026年9月27日 |
| 原因 | 第三者による不正アクセス(国外からと推測) |
| 現状 | 被害箇所を特定し対策済み。影響範囲と原因は調査中 |

## 時系列

- **9月20日** メトポのメール配信サービスで不具合が発生[^2]
- **9月25日** 国外からと推測される第三者による不正アクセスを確認[^2]
- **9月27日** 公表[^1]

## 漏えいした可能性がある情報

- **対象**: メトポ会員が登録しているメールアドレスのうち、送信不能のため東京メトロ側で配信を停止していたメールアドレス約59,000件[^1]
- **項目**: メールアドレスのみ(当該サーバーにはメールアドレス以外の会員情報は含まれていない)[^1]

## 現状

- 不正アクセスされた被害箇所を特定し、対策を実施済み[^1]
- 影響範囲と原因の詳細は調査中[^1]
- 対象者にはメトロポイントクラブ事務局からメールで連絡。ほかの手続きや外部サイトへの誘導は行わないとしている[^1]
- 問い合わせ窓口: 公式発表[^1]を参照

## コメント

漏えいの可能性があるのはメールアドレスのみで、しかも配信を停止していた(送信できなかった)アドレスに限られるので、ほかの事例と比べると影響は限定的です。

とはいえ、公式からの連絡メールが届くタイミングに合わせて、東京メトロを装ったフィッシングメールが紛れ込むのはよくあるパターンです。上記の送信元以外からのメトポ関連メールには注意しておきましょう。
