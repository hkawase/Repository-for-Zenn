## はじめに

どうも、セキュリティベンダーでコンサル/脆弱性診断/ペンテストなどをチョットダケやってるkawaseです。

「ニッポンレンタカーアプリ」で発生した不正アクセスについて、要点だけさくっとまとめました。2回に分けて公表されているので、あわせて整理しています。

通勤時間のオトモにでも( ´･ω･)⊃旦

## ざっくり概要

| 項目 | 内容 |
| --- | --- |
| 企業名 | ニッポンレンタカーサービス株式会社 |
| サービス | ニッポンレンタカーアプリ(NRアプリ) |
| 被害件数 | 41名(9月26日公表分)+55名(10月1日公表分) |
| 公表日 | 2026年9月26日、10月1日 |
| 原因 | 第三者による不正アクセス。10月1日公表分は、最初の件とは別の手法による攻撃 |
| 現状 | 封じ込め措置を実施済み。二次被害は確認されていない |

## 時系列

- **9月19日〜21日** 外部からアプリのシステムへの攻撃(10月1日公表分)[^2]
- **9月26日** 不正アクセスにより会員41名の情報が閲覧されたおそれがあると公表[^1]
- **9月29日** 最初の件を調査する中で、別の手法による不正アクセスを確認[^2]
- **10月1日** 別手法の不正アクセスで、新たに会員55名の情報が閲覧されたおそれがあると公表[^2]

## 閲覧されたおそれがある情報

9月26日公表分、10月1日公表分ともに対象の項目は同じです[^1][^2]。

- **全員**: 氏名、電話番号、メールアドレス、ログインID、利用履歴、予約情報
- **運転免許証情報を登録していた人**: 免許証番号、住所、生年月日
- **クレジットカードを登録していた人**: カード番号の下4桁、名義人名

## 現状

- 必要な対策と封じ込め措置を実施済みで、新たな被害は確認されていない[^2]
- 個人情報の不正利用などの二次被害は確認されていない[^2]
- 対象の会員には登録メールアドレス宛てに個別連絡。9月26日公表分の対象者にはパスワードの再設定を依頼[^1][^2]
- 個人情報保護委員会へ報告し、警察にも相談済み[^1][^2]
- 案内メールが届いていない会員は、現時点で閲覧のおそれは確認されていないとしている[^1][^2]
- 問い合わせ窓口: 公式発表[^2]を参照

## コメント

件数自体は合計で100名弱と小規模ですが、最初の件の調査中に「別の手法」による侵入が見つかっている点が気になります。攻撃者が複数の入口を試していたとも読めるので、追加の公表がないか引き続き見ておきたいところです。

奇しくもタイムズカーの公表の翌日の発表で、カーシェア・レンタカー系のサービスで免許証情報の漏えいが続いた形です。該当する人は、免許証情報を使ったなりすましにも注意してください。
