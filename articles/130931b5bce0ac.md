## はじめに

どうも、セキュリティベンダーでコンサル/脆弱性診断/ペンテストなどをチョットダケやってるkawaseです。

ロート製薬の通信販売で使っているシステムで発生した不正アクセスについて、要点だけさくっとまとめました。

通勤時間のオトモにでも( ´･ω･)⊃旦

## ざっくり概要

| 項目 | 内容 |
| --- | --- |
| 企業名 | ロート製薬株式会社 |
| サービス | 通信販売の顧客対応システム、顧客管理システム |
| 被害件数 | 調査中(攻撃者は顧客情報約395万件、通話録音約85万件の取得を主張。会社側は未確認) |
| 公表日 | 2026年9月11日(初報)、9月15日(調査状況) |
| 原因 | 第三者による不正アクセス(詳細は調査中) |
| 現状 | 影響範囲・件数を調査中。主要な業務への影響はなし |

## 時系列

- **9月10日** 通信販売で使っているシステムで、不正アクセスの可能性がある事象を確認。アクセス制限などの措置を実施[^1]
- **9月11日** 初報を公表[^1]
- **9月15日** 調査状況を公表。通話音声データと顧客管理システムの情報が不正に取得された可能性があるとし、個人情報保護委員会へ報告[^2]
- **9月中旬** 海外のサイバー犯罪フォーラムで、攻撃者を名乗る人物が約4TBのデータを取得したと主張[^3]

## 取得された可能性がある情報

- **通信販売の顧客対応システム**: 顧客との通話音声データと、それに付随する情報[^2]
- **顧客管理システム**: 不正アクセスにより情報が取得された可能性[^2]

具体的な項目や件数、対象の顧客は調査中です[^2]。

攻撃者側は、顧客情報約395万件や通話録音約85万件などを含む約4TBのデータを取得したと主張していますが、ロート製薬はこの件数を確認していないとしています[^3]。

## 現状

- 外部の専門機関の協力を得て、取得された可能性がある情報の範囲や件数、対象の顧客を調査中[^2]
- 個人情報保護委員会へ報告済み。警察や関係機関と連携して対応中[^2]
- 主要な業務への影響は確認されていない[^2]
- 再決済・本人確認・返金などを理由に、クレジットカード情報や暗証番号、パスワードを求める不審な連絡に応じないよう呼びかけている[^2]
- 問い合わせ窓口: 公式発表[^2]を参照

## コメント

漏えいの可能性があるのが「通話音声データ」という点が珍しく、そして厄介です。音声は名前や住所と違って変更できないうえ、生成AIで声を真似る技術も手軽になってきているので、なりすましに悪用されるリスクも頭に入れておく必要があります。

9月15日の続報以降、公式からの新しい発表はなく、攻撃者の主張する件数とのギャップも埋まっていない状態です。通販を利用したことがある人は、続報をチェックしておきましょう。
