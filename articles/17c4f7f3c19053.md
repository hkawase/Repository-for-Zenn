## はじめに

どうも、セキュリティベンダーでコンサル/脆弱性診断/ペンテストなどをチョットダケやってるkawaseです。

佐川急便の「お荷物問い合わせサービス」で発生した不正アクセスについて、要点だけさくっとまとめました。

通勤時間のオトモにでも( ´･ω･)⊃旦

## ざっくり概要

| 項目 | 内容 |
| --- | --- |
| 企業名 | 佐川急便株式会社 |
| サービス | お荷物問い合わせサービス(Webサイト) |
| 被害件数 | 調査中(9月30日からさかのぼって約100日分の荷物データなどが対象になり得る) |
| 公表日 | 2026年9月30日(第1報)、10月1日(第2報・第3報) |
| 原因 | 第三者による不正アクセス(原因・影響範囲は調査中) |
| 現状 | Webサービスの一部を停止中。集荷・配達は通常どおり |

## 時系列

- **9月30日** お荷物問い合わせサービスへの不正アクセスを確認し、アクセスを一部制限。同日に第1報を公表[^1]
- **10月1日** 第2報。個人情報が外部に流出した可能性があると公表し、Webサービスの一部を停止[^2]
- **10月1日** 第3報。本件専用のコールセンターを開設[^3]

## 漏えいした可能性がある情報

- **荷物の送り主・届け先**(9月30日からさかのぼって約100日分): 氏名(法人は法人名・担当者名)、住所、電話番号[^2]
- **運賃契約を結んでいる法人・個人**: 氏名(法人は法人名・担当者名)、住所、電話番号[^2]
- **Webサービス「スマートクラブ」の登録者**: 氏名(法人は法人名・担当者名)、住所、電話番号、メールアドレス、スマートクラブの会員ID[^2]

クレジットカード情報とパスワードは含まれていません。対象の件数と範囲は調査中です[^2]。

## 現状

- 以下のWebサービスを停止中[^2]
  - インターネット貨物お荷物問い合わせ(API含む)
  - 飛脚宅配便受付、飛脚往復便受付、飛脚往復便(ゴルフ)受付
  - 商品回収返金サービス、受取先変更、回収くん
- 集荷・配達は通常どおり[^2]
- 影響範囲と原因は引き続き調査中[^3]
- 佐川急便を装った不審なメール・SMS・電話への注意を呼びかけている[^2]
- 専用コールセンター: 0120-28-3449(9:00〜17:00、土日祝含む)[^3]

## コメント

送り主・届け先の氏名、住所、電話番号がセットで出ている可能性があるのが厄介です。ただでさえ多い宅配業者を装った不在通知SMSが、「実際に荷物をやり取りした相手の名前入り」でもっともらしく作られてしまうおそれがあります。

同じ時期にヤマト運輸・日本郵便でも不正アクセスが公表されているので、宅配関連のSMSやメールのリンクは踏まず、公式アプリや公式サイトから追跡番号を確認するクセをつけておくのが無難です。
