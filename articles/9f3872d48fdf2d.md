## はじめに

どうも、セキュリティベンダーでコンサル/脆弱性診断/ペンテストなどをチョットダケやってるkawaseです。

吉野家ホールディングスが公表した、アルバイト応募者の個人情報漏えいについて、要点だけさくっとまとめました。吉野家自身ではなく、以前の委託先が不正アクセスを受けた事例です。

通勤時間のオトモにでも( ´･ω･)⊃旦

## ざっくり概要

| 項目 | 内容 |
| --- | --- |
| 企業名 | 株式会社吉野家ホールディングス(吉野家、はなまる) |
| サービス | 委託先・株式会社ApplyNowの採用管理プラットフォーム |
| 被害件数 | 応募者5,366件(吉野家4,998件、はなまる368件)+グループ従業員418件 |
| 公表日 | 2026年9月30日 |
| 原因 | データ分析ツールの脆弱性を悪用した不正アクセス |
| 現状 | 経路は遮断済みで脆弱性も修正済み。二次被害は確認されていない |

## 時系列

- **2022年4月11日〜2024年6月30日** 吉野家とはなまるが、アルバイト採用業務の一部をApplyNowに委託[^1]
- **2026年8月9日〜9月7日** ApplyNowの採用管理プラットフォームで、データ分析ツールの脆弱性を悪用した不正アクセスが発生[^1]
- **9月7日** データベースから一部のデータが不正に出力される。ApplyNowが異常なアクセスログを検知し、不正アクセスを遮断[^1]
- **9月16日** ApplyNowから吉野家HDへ、応募者などの情報が漏えいした可能性があると連絡[^1]
- **9月21日** 吉野家HDが個人情報保護委員会へ報告[^1]
- **9月28日** 契約終了後も応募者の情報がApplyNowのデータベースに残っていたことを確認[^1]
- **9月30日** 公表[^1]

## 漏えいした情報

- **面接シェアリングサービス「Interview Cloud」経由の応募者**: 氏名(カナ)、メールアドレス、電話番号、生年月日、性別、一部の人は住所・職業[^1]
- **録画面接「ApplyNow」経由の応募者**: 氏名(カナ)、メールアドレス、電話番号[^1]
- **採用に関わるグループ従業員(418件)**: 採用担当者のユーザー名、メールアドレス、暗号化されたパスワード、権限[^1]

面接の録画データは別の保管領域にあり、不正アクセスは確認されていません。従業員の件数はアカウント数で、人数とは一致しないとしています[^1]。

## 現状

- 不正アクセスの経路は遮断済みで、原因となった脆弱性も修正済み[^1]
- 二次被害は確認されていない。吉野家HD側のシステムへの不正アクセスも確認されていない[^1]
- 対象者には10月1日以降、吉野家HDとApplyNowからメールで案内。対象者が行う手続きはない[^1]
- 残っていたデータは、調査や対象者対応が終わり次第、速やかに消去するとApplyNowから説明を受けている[^1]
- 問い合わせ窓口: ApplyNow 0120-401-373(全日 9:00〜18:00)、吉野家HD お客様相談室 0120-69-5114(9:00〜17:00)[^1]

## コメント

一番のポイントは、契約が終わって本来は消されているはずの応募者情報が、委託先に残ったままだったことです。吉野家HDは「契約終了とともに消去される」と認識していたものの、実際の運用は違っていたとしています。

委託先に預けたデータを契約終了時に本当に消したのか、削除証明などで確認するところまでやらないと、こうした「もう関係ないはずの委託先」から漏れるリスクは残り続けます。耳が痛い組織も多いのではないでしょうか。
