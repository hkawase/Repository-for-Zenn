## はじめに

どうも、セキュリティベンダーでコンサル/脆弱性診断/ペンテストなどをチョットダケやってるkawaseです。

チケット販売サイト「イープラス」で発生した不正アクセスについて、要点だけさくっとまとめました。

通勤時間のオトモにでも( ´･ω･)⊃旦

## ざっくり概要

| 項目 | 内容 |
| --- | --- |
| 企業名 | 株式会社イープラス |
| サービス | 電子チケット「スマチケ」の払戻し情報を管理するシステム |
| 被害件数 | 1,463件 |
| 公表日 | 2026年9月29日 |
| 原因 | 第三者による不正アクセス |
| 現状 | 不正アクセスは遮断済み。対象者へ個別にメールで連絡中 |

## 時系列

- 9月11日 19:58〜9月12日 2:44: 払戻し情報を管理するシステムへの不正アクセスが複数回発生[^1]
- 9月14日〜15日: 不正アクセスと個人情報の漏えいを確認。15日中にセキュリティ設定を見直し、不正アクセスを遮断[^1]
- 9月29日: 公表。対象者への個別メールを開始[^1]

## 漏えいした情報

2022年6月30日〜2026年9月11日にスマチケから払戻しを申請した人のうち、一部の情報が対象です。返金方法によって漏えいした情報が異なります[^1]。

| 返金方法 | 件数 | 漏えいした情報 |
| --- | --- | --- |
| 銀行振込 | 751件 | メールアドレス、カナ氏名、振込先口座情報(金融機関名・支店名・口座種別・口座番号・口座名義) |
| クレジットカード返金 | 644件 | メールアドレス、カナ氏名 |
| 郵便振替払出証書 | 68件 | メールアドレス、カナ氏名、払出証書の送付先(郵便番号・住所・氏名) |

いずれも、払戻し対象の公演名・会場・開催日時が含まれています。クレジットカード情報やパスワードは漏えいしていません[^1]。

## 現状

- 不正アクセスは遮断済みで、その後同様の事象は発生していない[^1]
- 管理下の全システムを再検査し、ほかに漏えいや不正アクセス、改ざんがないことを確認[^1]
- 対象者(イープラス会員ではない同行者も含む)には9月29日から順次メールで連絡[^1]
- 個人情報保護委員会へ報告済み。所轄の警察署への届出を準備中[^1]
- 問い合わせ窓口: 公式発表[^1]を参照

## コメント

件数は1,463件と昨今の事例と比較するとそこまで多くはないものの、銀行振込で返金を受けた人は口座情報まで漏えいしています。口座番号だけで勝手にお金を引き出されることは基本的にありませんが、「返金の手続きに不備があった」などと口座情報や暗証番号を聞き出そうとする詐欺には使われやすい情報です。

公演名や開催日時まで含まれているので、「〇〇公演の払戻しについて」といった本物らしい連絡にも注意してください。
