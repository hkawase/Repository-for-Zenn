## はじめに

どうも、セキュリティベンダーでコンサル/脆弱性診断/ペンテストなどをチョットダケやってるkawaseです。

日本郵政・日本郵便の「郵便局アプリ」で発生した不正アクセスについて、要点だけさくっとまとめました。

通勤時間のオトモにでも( ´･ω･)⊃旦

## ざっくり概要

| 項目 | 内容 |
| --- | --- |
| 企業名 | 日本郵政株式会社、日本郵便株式会社 |
| サービス | 郵便局アプリ、ゆうID |
| 被害件数 | 69件(19人分) |
| 公表日 | 2026年9月29日 |
| 原因 | 外部からの不正アクセス(手口は非公表) |
| 現状 | 9月26日にサービス再開。不正利用の形跡は確認されていない |

## 時系列

- **9月25日 22:30ごろ** 外部からの不正アクセスを受け、ゆうIDと郵便局アプリの緊急メンテナンスを実施[^1]
- **9月26日** 必要な調査と対策を行ったうえでサービスを再開[^1]
- **9月29日** 69件(19人分)の情報が不正に取得されたと公表[^1]

## 漏えいした情報

人によって異なりますが、次の3種類の情報が不正に取得されました[^1]。

- **ゆうIDの会員情報**: 氏名、住所、生年月日、性別、電話番号、メールアドレス(登録している場合は勤務先情報、家族状況、住所録登録情報も)
- **ゆうIDの住所録に登録されていた情報**: 氏名、住所(登録している場合は企業名、電話番号、メールアドレスも)
- **郵便局アプリで作成した送り状情報**: 差出人・受取人の氏名、住所、電話番号など、追跡番号、品名、発送・配達予定情報

## 現状

- サービスは9月26日に再開済み[^1]
- 不正に取得された情報が悪用された形跡は確認されていない[^1]
- 該当する人には、準備が整い次第、書面などで個別に連絡するとしている[^1]
- 問い合わせ窓口: 公式発表[^1]を参照

## コメント

件数は19人分と少なめで、検知から緊急メンテナンス、翌日の再開までの動きも早かった印象です。一方で、手口については公表されていません。

取られた情報には追跡番号や品名、配達予定まで含まれています。「〇日にお届け予定の〇〇について」といった、実際の荷物に合わせた詐欺メッセージを作れてしまう情報なので、該当する人は郵便局を名乗る連絡に注意してください。。

ヤマト・佐川・日本郵便いずれも漏洩しているため、不在通知の連絡系は一律でURLなどは踏まず、必ずブクマした公式ページから確認するか、アプリを使うようにすることが安全と思います。（まあ、そのアプリが糸口になったワケですが）
