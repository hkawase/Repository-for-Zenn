## はじめに

どうも、ひよっ子セキュリティコンサルタントのhkawaseです。

パーク24が運営するカーシェア「タイムズカー」で発生した不正アクセスについて、要点だけさくっとまとめました。

## ざっくり概要

| 項目 | 内容 |
| --- | --- |
| 企業名 | パーク24株式会社 |
| サービス | タイムズカー(カーシェアリング) |
| 被害件数 | 約660万件(うち本人確認書類の画像が約160万件) |
| 公表日 | 2026年9月25日(第1報)、9月28日(第2報)、9月29日(第3報) |
| 原因 | 第三者による不正アクセス(侵入経路は調査中) |
| 現状 | 不正アクセス経路は遮断済み。サービスは通常どおり提供中 |

## 時系列

- **9月25日 9:07** 不正アクセスを検知し、調査を開始。同日に第1報を公表[^1]
- **9月26日 7:25** 不正アクセスの経路を遮断[^1]
- **9月28日** 第2報。会員情報など約660万件が第三者に取得されたことを確認[^2]
- **9月29日** 第3報。本人確認書類の画像の漏えいが約160万件と判明。対象者へのメール連絡を開始[^3]

## 漏えいした情報

- **約660万件の対象**: タイムズカー会員、退会済み会員、入会手続きが完了していない人、タイムズビジネスサービス会員[^2]
- **主な項目**: 氏名、住所、生年月日、電話番号、メールアドレス、運転免許情報、パスワード、連携サービスID(JR西日本の「WESTER ID」など9サービス)、法人会員の所属部署名[^2]
- **本人確認書類(約160万件)**: 運転免許証の画像、現住所確認書類の画像(公共料金の請求書など)、学生証の画像(学生プラン)、家族確認書類の画像(家族プラン)[^3]

なお、パスワードは「復元できない形式」で保管されていたため、アカウントが不正に利用される危険性はないとしています。クレジットカード情報の漏えいはないことも確認済みです[^2]。

## 現状

- 不正アクセスの経路は遮断済みで、その後に新たな不正アクセスは確認されていない[^2]
- 個人情報保護委員会と警察に報告済み。外部の専門機関によるフォレンジック調査を実施中[^2]
- 本人確認書類が漏えいした対象者には、9月29日からメールで個別に連絡。2週間程度をめどに改めて案内するとしている[^3]
- パーク24を装ったメール・SMS・電話への注意を呼びかけている[^3]
- 問い合わせ窓口: 0120-25-8924(24時間)[^3]

## 一言コメント

退会済みの人や入会手続きを途中でやめた人の情報まで漏えいの対象に入っている点が気になります。使い終わった本人確認書類の画像をいつまで保管するのか、という保管期間の設計が問われる事例だと感じました。

身に覚えのある人は、タイムズカーを装ったフィッシングに特に注意しましょう。
