## はじめに

どうも、セキュリティベンダーでコンサル/脆弱性診断/ペンテストなどをチョットダケやってるkawaseです。

北海道のコンビニ「セイコーマート(セコマ)」のスマホアプリで発生した不正アクセスについて、要点だけさくっとまとめました。

通勤時間のオトモにでも( ´･ω･)⊃旦

## ざっくり概要

| 項目 | 内容 |
| --- | --- |
| 企業名 | 株式会社セイコーマート |
| サービス | セイコーマートアプリ |
| 被害件数 | 572,022人分(アプリ会員の49%) |
| 公表日 | 2026年9月29日(第一報・第二報)、9月30日(第三報) |
| 原因 | 第三者による不正アクセス(手法は警察と連携中のため非開示) |
| 現状 | アプリでの新規入会や会員情報変更、公式通販などを停止中 |

## 時系列

- **9月24日 22時〜23時** クラブカードの退会処理が不正に行われたアカウントが1件見つかる[^1]
- **9月28日 17時過ぎ** アプリのサーバーを経由して、会員情報を保有するサーバーに不正アクセスされた可能性が判明。20時に当該サーバーへの接続を停止[^1]
- **9月29日** 第一報で約57万アカウントが対象になり得ると公表[^1]。同日の第二報で、購買履歴は漏えいしていないことと、公式通販などのログインも停止したことを追加で報告[^2]
- **9月30日** 第三報。572,022人分の情報が閲覧されたことを確認[^3]

## 漏えいした情報

- **対象**: セイコーマートアプリに登録したことがある会員のうち572,022人(アプリ未登録の人は対象外)[^3]
- **項目**: 姓名、性別、生年月日、住所、電話番号、メールアドレス、クラブカードの入会年月日・退会年月日[^1]

パスワードと購買履歴は漏えいしていません。クレジットカード情報はそもそも保有していないとしています[^1][^2]。

## 現状

- アプリでの新規入会・登録カードの変更、マイページでの会員情報変更・退会、公式通販サイトは停止中。再開時期は改めて知らせるとしている[^3]
- ペコママネーの利用・チャージ、ポイント付与、会員価格での購入、クーポンは引き続き利用可能。新規入会と会員情報変更は店頭で受け付けている[^3]
- 個人情報保護法に基づき行政当局へ報告済み。外部調査会社や警察と連携して調査中[^3]
- 9月末で失効するポイントは1か月延長[^2]
- セイコーマートを装ったメールへの注意を呼びかけている[^3]
- 問い合わせ窓口: 0120-89-8551(月〜土 9:00〜17:00)[^3]

## コメント

「不正な退会処理が1件だけあった」という小さな違和感から、会員サーバーへの不正アクセスにたどり着いた流れはちょっと興味深いです。ただ、結果的にはアプリ会員の約半数の情報が閲覧されており、規模はかなり大きめ。

住所や生年月日まで含まれているので、身に覚えのある人はセイコーマートを装ったメールやSMSに加え、宛名入りの郵便物などにも気を付けておくとよさそうです。
