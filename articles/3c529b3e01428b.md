## はじめに

どうも、セキュリティベンダーでコンサル/脆弱性診断/ペンテストなどをチョットダケやってるkawaseです。

米国防総省の人事データを管理する組織で発生した個人情報漏えいについて、要点だけさくっとまとめました。

通勤時間のオトモにでも( ´･ω･)⊃旦

## ざっくり概要

| 項目 | 内容 |
| --- | --- |
| 組織名 | 米国防総省 国防人材データセンター(DMDC) |
| サービス | DMDCのファイル共有システム |
| 被害件数 | 約305万人(存命の人 約276万人、亡くなった人 約29.4万人) |
| 公表日 | 2026年9月18日付で対象者に通知、9月24日に初報道、9月29日に国防総省当局者が件数を認める |
| 原因 | ファイル共有システムの脆弱性 |
| 現状 | 脆弱性は修正済み。悪用の兆候は確認されていない |

DMDCは、軍人・退役軍人・職員・契約業者・軍人家族など6,000万人超の記録を管理する、国防総省の人事データの中枢です[^3]。

## 時系列

- **2025年10月〜2026年7月16日** 少数の権限のない利用者が、暗号化されていない個人情報を含むファイルにアクセス[^1][^2]
- **2026年7月16日** DMDCが脆弱性を発見し、修正[^1][^2]
- **9月18日** 対象者への通知書簡の日付[^1][^2]
- **9月24日** Military Timesが報道。この時点では件数は非公表[^1]
- **9月29日** 国防総省当局者が、約305万人が影響を受けたとメディアに認める[^2][^3]

## 漏えいした情報

- **項目**: 氏名、社会保障番号(SSN)、生年月日、連絡先、性別、人種、職種などの軍の人事情報[^1][^3]

## 現状

- ファイル共有システムの脆弱性は修正済み[^3]
- 情報が悪用された兆候は確認されていないとしている[^1][^2]
- 対象者には、IDXによるクレジットモニタリングと身元回復サービスを1年間無料で提供[^1][^2]

## コメント

暗号化されていない個人情報がファイル共有システムに置かれていて、約9か月にわたって不正にアクセスされ続けていた、というのがかなり痛いポイントです。さらに発見から対象者への通知まで約2か月、件数が明らかになるまでさらに10日ほどかかっています。

米国ではSSNが本人確認の要として使われているため、なりすましによる口座開設などの被害につながりやすい情報です。日本のマイナンバーの扱いを考えるうえでも参考になる事例だと思います。
