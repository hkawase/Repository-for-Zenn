どうも、セキュリティベンダーでコンサル/脆弱性診断/ペンテストなどをチョットダケやってるkawaseです。

京王電鉄グループで発生したランサムウェア被害について、要点だけさくっとまとめました。

通勤時間のオトモにでも( ´･ω･)⊃旦

## ざっくり概要

| 項目 | 内容 |
| --- | --- |
| 企業名 | 京王電鉄株式会社(京王グループ) |
| サービス | グループのサーバー(一部グループ会社の営業システム) |
| 被害件数 | 情報漏えいは現時点で確認されていない |
| 公表日 | 2026年9月26日 |
| 原因 | ランサムウェアによる攻撃(侵入経路は調査中) |
| 現状 | 鉄道の運行に支障はなし。決済や予約などに影響 |

## 時系列

- **9月26日未明** グループのサーバーへのランサムウェア攻撃を確認。被害拡大を防ぐためネットワークを遮断し、警察に通報[^1]
- **9月26日** 京王電鉄が公表。京王プラザホテルなどグループ各社も障害を告知[^1][^2]
- **9月27日〜28日** 京王ストア、京王百貨店、京王観光などが影響を公表[^2]

## 影響を受けた主なサービス

京王電鉄の発表では、一部グループ会社の営業システムに支障が出ているとしています[^1]。各社の告知をまとめると、主な影響は次のとおりです[^2]。

| 会社 | 主な影響 |
| --- | --- |
| 京王電鉄 | 問い合わせフォーム、団体乗車券の申込みなど |
| 京王プラザホテル | 問い合わせ対応の遅れなど |
| 京王プレッソイン | 新規予約の受付停止、チェックイン・アウトの遅れ |
| 京王ストアなど | クレジットカード決済の障害、京王ポイントの付与・利用不可 |
| 京王百貨店 | クレジットカード決済、ポイント利用不可 |
| 京王観光 | オンライン予約の停止など |
| 京王バス | 定期券窓口でクレジットカードが使えない |

## 現状

- 鉄道の運行に支障はない[^1]
- 情報漏えいの事実は現時点で確認されていないが、機密情報や顧客情報の流出も含めて調査中[^1]
- 外部専門家の協力を得て、攻撃の経路や被害を調査中[^1]
- 問い合わせ窓口: 公式発表[^1]を参照

## コメント

鉄道の運行は止まらなかった一方で、スーパーの決済やホテルの予約といった「生活に近い」営業システムが軒並み影響を受けています。グループで多角的に事業を展開していると、共通基盤がやられたときの影響が広い範囲に一気に出るのがわかる事例です。

現時点で情報漏えいは確認されていませんが、最近のランサムウェアはデータを盗んでから暗号化する「二重脅迫」が主流です。今後の調査結果で漏えいが判明する可能性もあるので、続報は追っておきたいところです。
